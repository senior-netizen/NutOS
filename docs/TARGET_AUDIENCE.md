# 🎯 NutOS Target Audience
*Rodent, Inc. | SquirrelLabs Technologies*

---

## Purpose

This document defines who NutOS serves first, what each audience needs, and how those needs map to product priorities.

---

## Primary Audiences

## 1) Privacy-Conscious Consumers

**Profile**
- Everyday users who want a modern OS without surveillance defaults.

**Needs**
- Simple setup and understandable privacy controls
- Reliable app availability for daily workflows
- Strong defaults without technical tuning

**NutOS value**
- Zero-telemetry default posture
- Clear, granular permission prompts
- Familiar desktop interactions via Acorn

## 2) Developers & Technical Creators

**Profile**
- Software engineers, data practitioners, DevOps users, and open-source contributors.

**Needs**
- Fast terminal + GUI workflow
- Toolchain flexibility and container support
- Reproducible, auditable platform behavior

**NutOS value**
- Linux-native compatibility via NutKernel
- Deep customization and scripting capability
- Transparent security/update model

## 3) Power Users & Gamers

**Profile**
- Users who require high performance, wide hardware support, and software compatibility.

**Needs**
- Strong graphics stack and low-latency behavior
- Access to Windows-centric game/app ecosystem
- Stability under heavy multitasking

**NutOS value**
- WinBridge + DXVK/VKD3D pathway via NutShell
- Performance-first kernel and compositor tuning
- Flexible display and input configuration

## 4) Education & Public Sector

**Profile**
- Institutions requiring cost control, security, and device longevity.

**Needs**
- Manageability at scale
- Compliance-oriented controls and auditing
- Hardware-agnostic deployment model

**NutOS value**
- Open architecture with predictable lifecycle
- Policy-friendly permissioning and updates
- Works on diverse hardware fleets

---

## Secondary Audiences

- Small businesses replacing aging Windows fleets
- Creative professionals seeking customization + privacy
- Emerging-market users relying on older hardware

---

## Non-Goals (v1)

- Consumer mobile-first operating system replacement
- Embedded/IoT-first distribution strategy
- Legacy 32-bit compatibility as a primary roadmap driver

---

## Product Prioritization Implications

1. **Onboarding clarity** outranks advanced niche features.
2. **Compatibility gains** directly impact adoption curve.
3. **Security UX** must stay understandable for non-technical users.
4. **Hardware certification** should prioritize common consumer and education devices.
