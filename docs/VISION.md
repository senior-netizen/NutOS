*Rodent, Inc. | SquirrelLabs Technologies*

## Mission Statement

> **To build the world's most open, private, and capable operating system — one that every person on earth can use, trust, and own.**

---

## Vision

NutOS exists because no operating system today fully respects its user.

- **macOS** is beautiful but expensive and locked down.
- **Windows** is ubiquitous but invasive and bloated.
- **Linux** is free and powerful but demands too much technical knowledge.

NutOS is the OS that closes every gap. It is built on the belief that a user deserves:

1. **Full ownership** of their device and data
2. **Zero compromise** on usability, compatibility, or performance
3. **Freedom** to customize, modify, and extend everything
4. **Security and privacy** as defaults — not paid upgrades

---

## Core Philosophy

### 1. The User Is the Owner
NutOS belongs to the person running it. Not SquirrelLabs Technologies. Not advertisers. Not governments. The user controls every aspect of the system — what runs, what is shared, what is stored, and what is updated.

### 2. Privacy Is a Right, Not a Feature
Privacy is built into NutOS at the kernel level. It is not a settings menu or a paid tier. No telemetry is collected without explicit, informed, reversible consent. Crash reports, usage analytics, and diagnostics are always opt-in.

### 3. Complexity Should Be Optional
NutOS is accessible to a first-time computer user. Every task that can be done via a GUI will have a GUI. The terminal is available for those who want it, but it is never required. Power is available without friction.

### 4. Open Source Is Non-Negotiable
The NutOS kernel, desktop environment (Acorn), and all core utilities are open source. Anyone can audit, fork, or contribute. Transparency is not marketing — it is architecture.

### 5. Compatibility Is a First-Class Concern
NutOS will not ask users to give up their existing software. Through NutShell (our compatibility layer), users can run the Windows and Linux applications they already rely on. We come to the user — they do not come to us.

### 6. Performance Respects the Hardware
NutOS does not assume the user has a new machine. It is optimized for modern ARM and x86-64 systems but can run meaningfully on hardware from 10+ years ago. A lean OS is a respectful OS.
