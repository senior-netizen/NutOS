# 🗺️ NutOS Development Phases
*Rodent, Inc. | SquirrelLabs Technologies*

---

## Phase 1 — Foundations

**Objective:** establish a stable, bootable platform with core UX and security primitives.

**Milestones**
- NutKernel baseline and packaging flow
- NutInit service manager MVP
- Acorn shell prototype with core window management
- NutShell LinuxRun MVP
- Initial installer and update flow

**Exit Criteria**
- Daily-driver viability for internal teams
- Repeatable install/upgrade path

---

## Phase 2 — Compatibility & UX Maturity

**Objective:** close adoption blockers for mainstream users.

**Milestones**
- WinBridge compatibility expansion
- DroidShell beta integration
- Acorn accessibility and polish pass
- Security dashboard and permissions UX refinement
- Expanded hardware certification matrix

**Exit Criteria**
- Broad app coverage for target user workflows
- Stable performance on certified consumer hardware

---

## Phase 3 — Scale & Enterprise Readiness

**Objective:** operational maturity for larger deployments.

**Milestones**
- RISC-V platform bring-up (targeted)
- Fleet policy/management foundations
- Compliance evidence program (ISO/SOC-related controls)
- Long-term support branch process

**Exit Criteria**
- Predictable release cadence and support lifecycle
- Institutional pilot readiness

---

## Ongoing Cross-Phase Streams

- Security response and hardening
- Internationalization and accessibility
- Developer ecosystem and documentation
- Performance benchmarking and regression prevention
