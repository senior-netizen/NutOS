# 🐿️ NutOS — by Rodent, Inc. (A SquirrelLabs Technologies Division)

> *"Collect Everything. Waste Nothing."*

**NutOS** is an open-source, privacy-first, universal-compatibility operating system developed by **Rodent, Inc.**, the OS division of **SquirrelLabs Technologies**. It is designed to close every gap left by macOS, Windows, and Linux — delivering polish, freedom, security, and compatibility in a single unified platform.

---

## Why NutOS?

| Problem | Current OS | NutOS Solution |
|---|---|---|
| Expensive hardware lock-in | macOS | Runs on any x86, ARM, RISC-V hardware |
| Privacy violations & telemetry | Windows | Zero telemetry. Fully auditable. |
| Too complex for beginners | Linux | World-class GUI — no terminal required |
| Poor app/game compatibility | Linux | Universal compatibility layer (NutShell) |
| Bloat & forced updates | Windows | Lean kernel, user-controlled updates |
| Low customizability | macOS | Full control — every pixel, every behavior |
| Security vulnerabilities | Windows | Sandboxed apps, hardware-level security |

---

## Core Pillars

1. **🔓 Open** — Open-source kernel and core. Free forever.
2. **🔒 Private** — Zero data collection by default. You own your data.
3. **🎨 Polished** — Beautiful, consistent UI that rivals macOS.
4. **⚙️ Compatible** — Run Windows, Linux, and Android apps natively.
5. **🚀 Performant** — Optimized for ARM, x86, and RISC-V.
6. **🛡️ Secure** — Sandboxed apps, encrypted storage, silent patches.
7. **🧩 Customizable** — From the kernel up, everything can be changed.
